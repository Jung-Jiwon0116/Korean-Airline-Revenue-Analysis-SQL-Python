# Korean-Airline-Revenue-Analysis-SQL-Python
ICN-HKG route profitability and operational efficiency analysis using SQL and Python

## Key Objectives
- Revenue Optimization: Analyzed seat class profitability (Presitge vs Economy)
- Fleet Efficiency: dentified the most fuel-efficient aircraft models
- Synthesized 4,800+ booking records using Python Faker.

## Tech Stack
- Database: MySQL
- Language: SQL, Python
- Libraries: Pandas, Seaborn, Matplotlib, SQLAlchemy, Faker
